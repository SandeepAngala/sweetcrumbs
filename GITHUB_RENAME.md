# GitHub repository rename

The codebase now references:

**https://github.com/SandeepAngala/mana-ooru-mana-tea**

## Steps (GitHub)

1. Open https://github.com/SandeepAngala/sweetcrumbs/settings
2. Under **Repository name**, change to `mana-ooru-mana-tea`
3. Click **Rename**

GitHub redirects the old URL automatically.

## Update your local clone

```bash
git remote set-url origin https://github.com/SandeepAngala/mana-ooru-mana-tea.git
git push -u origin main
```

## Railway

The Railway hostname stays the same unless you change it in Railway settings. Keep `APP_URL` as your actual `*.up.railway.app` URL.
